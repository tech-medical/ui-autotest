# Branching

Documented baseline for **ui-autotest**: `main`.

- Agent work and pull requests target `main`.
- Create branches from `main`.
- This repository’s remote has `main` only. There is no `prod` branch, so `main` is the working baseline and the PR target. The org note that `main` may be storage-only applies only when a `prod` branch actually exists; it does not apply here.
- No test or release branch flow is documented for this repo. Do not invent one.
